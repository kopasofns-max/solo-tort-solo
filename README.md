## Описание файлов в архиве
1. `solo_coffee.html` — Исходный код страницы Кофейни Solo (с левым выравниванием на мобильных устройствах, карточкой перехода в Торт Solo, слайдером и скрытым котиком).
2. `tort_solo.html` — Исходный код страницы Кондитерской Торт Solo (с экспресс-баннером, двухуровневым меню, 40+ напитками, якорными кнопками, без галереи в хедере/футере и выровненным по верхнему краю hero-блоком). В файле убраны дубли карточек для сокращения веса кода, вы можете легко размножить их по примеру.
